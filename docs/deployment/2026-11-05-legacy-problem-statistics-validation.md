## 数据来源

- 完整V88快照仍优先，冻结统计不被当前结论替换。
- 专用历史快照缺失异常才进入旧规则：以该批出现记录或当前所属批次精确匹配的问题为成员，并集按问题ID去重；按成员的当前类型、状态和处理结论恢复问题数量、分类、未解决数量和解决率。
- 统计投影不读取或解析影响笔数，文字、负数、溢出等原值不影响可恢复的问题计数。
- 日报交易指标只用本批成员与本批原量解析器；周报交易指标保持已授权的同类最新结论策略。问题统计可恢复不等于允许借用后批影响笔数。
- 无问题成员，但原始各领域问题总数均明确为0时，可确认零问题统计；没有记录也没有零统计证明时才保留局部未知。
- 报表说明“本批问题记录与当前处理结论（旧规则，非当时快照）”，不将兼容统计冒充旧时间点的冻结状态。
