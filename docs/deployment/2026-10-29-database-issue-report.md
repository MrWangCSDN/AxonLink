# 回放数据库问题汇总报表交付说明

## 使用入口

登录后进入“回放数据库问题清单”，点击“导出报表”，选择最新业务批次或历史批次后下载 Excel。原“导出 Excel”继续导出清单明细。

汇总报表覆盖所选批次全部问题，不受列表分页和其他筛选条件影响。文件包含“领域汇总”和“统计口径”两个工作表，问题类型列读取数据库当前实际值。

## 统计说明

- 批次指标读取该批次最后一次导入的原始输入；问题类型及表所属领域采用数据库当前值。
- 表级数据量按表统计一次。字段差异为字段级差异数量之和，不能当作去重后的主键记录数。
- 参与比对的字段数采用当前唯一有效的字段登记配置；配置缺失或存在歧义时显示“—”。
- 旧批次未保留完整表级输入时，表级指标显示“—”，字段差异、问题类型和处理进度仍可导出。
- 合计进度根据合计问题数与未处理数计算，不能对各领域百分比直接求平均。

## 部署

本次前端已构建到 `src/main/resources/static`，与后端一同部署即可。后端使用 Java 17，统计查询要求 MySQL 8 或以上版本。

本功能复用既有批次、问题历史、表人员和字段登记数据，不新增数据库迁移。已有系统仍应按既有流程应用项目所需迁移。登录会话沿用现有认证，导入口令不能调用报表接口。

新增接口：

- `GET /api/ai/parallel-replay/database-issues/report/options`：完整可导出批次目录。
- `POST /api/ai/parallel-replay/database-issues/report/export`：请求体 `{"batchNo":"实际批次名"}`，省略批次默认最新业务批次，响应 XLSX。

## 验证记录

报表专项 21 项测试通过（包括独立本地临时 MySQL 库验证）；前端 33 个测试文件、554 项测试通过，生产构建通过。回放相关回归 815 项中 813 项通过、2 项可选 MySQL 测试跳过；两个已知存在基线失败的旧测试类未纳入本次回归命令。

常规报表专项验证：`mvn -Dtest='ReplayDatabaseIssueReport*Test' test`。真实 MySQL 验证需显式启用 `REPORT_MYSQL_REGRESSION=true` 并配置本地测试库权限；测试仅允许本地地址，使用独立临时数据库并在结束后清理。

本次验证使用 H2、MockMvc 和本地临时 MySQL 数据库，未启动连接真实业务数据库的完整服务。
