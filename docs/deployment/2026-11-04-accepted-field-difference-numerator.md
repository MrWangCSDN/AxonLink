# 字段差异认可交易计入比对通过率

本次部署新版后端，无需数据库迁移或前端重建。沿用已有接口比对明细中的两种成功数量，以及问题的交易码、审核状态和缺陷修复日期。

## 计入条件

按所选出现批次、领域及沙箱、交易码分别判断，交易码只去除首尾空白并保留前导零。该范围内至少存在一条“字段级、无需处理、审核通过”的问题，并且该交易全部字段级问题的缺陷修复日期均非空，才认可这个交易的有字段差异成功数量。任一日期为空就不补；历史审核通过但缺修复日期时也不兜底。

从同批次、同领域的接口比对 DETAIL 取数量，同交易码的多条 S 码明细正常相加，合计行不参与。每条接口明细只计算一次，不按匹配字段问题条数重复加。

## 计算与兼容

领域的 DETAIL 两种成功数量全部已知且非负时，直接使用真实拆分计数：

```text
比对通过率分子 = 无字段差异成功数量 + 失败响应码一致数量 + 符合条件的有字段差异成功数量
分母 = 发送交易量 − 响应码忽略 − 交易级且无需处理且审核通过的影响笔数
```

0 是有效计数。某领域无接口明细、缺少任一拆分计数或存在负数时，该领域沿用原通过率反推算法，不追加未知的有差异数量。聚合溢出直接报错，避免整数回绕。原接口成功率及问题总数/分类规则保持。

日报上一/当前批次、周报起止批次、页面汇总和 Excel 共用计算。合计按数量求和后重算百分比。基础“无字段差异”计数保持事实原值，认可差异不写入该字段。

已生成报告仍为快照，需在对应入口执行“重新生成”才应用新规则及最新处理结果。接口明细 Sheet 仍仅展示结束批次的数据。

验证：专项8项、原计算器10项、问题DAO36项、日报26项、周报9项，共89项相关回归通过，失败、错误和跳过均为0。覆盖真实数据库到Excel/汇总JSON、日期阻断、审核资格、多字段/多S码、批次/领域/沙箱隔离、旧数据回退、合计、零值和聚合溢出。
