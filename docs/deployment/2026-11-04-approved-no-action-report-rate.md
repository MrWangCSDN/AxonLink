# 汇总信息无需处理扣减的审核条件

本次部署新版后端即可生效，不新增数据库字段或迁移，前端资源无需重建。

汇总信息的“无需处理”交易量只累加问题级别为“交易级”、问题状态为“无需处理”、审核状态为 `APPROVED` 的影响笔数。待审核、未填写审核状态及未知状态均不参与；已有审核通过但审核原因为空的记录仍认可审核结论。

两类比例继续共用 `发送交易量 − 响应码忽略 − 已审核通过的交易级无需处理影响笔数` 分母。日报、周报、页面汇总、Excel 和合计行口径一致。问题总数及问题分类对无需处理的既有排除规则保持。

已有日报和周报是永久快照，更新后端或修改问题审核状态不会自动覆盖。需在对应报表入口选择批次并执行“重新生成”，才会重新查询当前问题状态、审核状态和影响笔数并更新 Excel 及汇总信息。

验证：计算器、问题 DAO、日报、周报四类回归共 79 项通过，失败、错误和跳过均为 0。新增真实数据库到 Excel/汇总 JSON 的回归，验证未审核不扣除、字段级及批次/沙箱隔离、批准后显式重新生成更新数量和比例。
