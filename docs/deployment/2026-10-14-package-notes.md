# 2026-10-14 源码包说明

本包包含当前后端源码和最新前端构建文件（`src/main/resources/static`）。数据库问题清单筛选窗口已加宽，中英文表名分行、长名称自动换行，选项按内容撑开行高，右侧计数不覆盖名称。

“修复待验证”的当天保护已经存在：仅当批次号中的日期晚于最近一次有效人工保存日期时重新打开，同日保持待验证。系统导入日期不参与这一比较。本次补充的回归测试覆盖系统日期与业务批次日期不同的情况。

## 已知问题

本次只构建并打包当前代码，以下审查发现尚未修复：

- 数据库问题清单同批次重复导入可能覆盖原导入状态翻转历史，导致首次翻转时间、操作人和前后状态无法准确追溯。
- 数据库问题跟踪按批次号字符串排序，非补零序号可能使“最新批次”标识不正确；同批次先出现再消失时，原始数据仍可能展示此前出现时的内容。
- 原回放问题清单同一已知批次“出现、消失自动修复、再出现”存在最后一次翻转未进入跟踪历史的边界问题；跨日更新审核原因后再次导入，缺陷修复日期也存在漂移。

生产部署前应评估上述跟踪记录问题。当天保护机制与历史覆盖缺陷是不同的代码路径。
