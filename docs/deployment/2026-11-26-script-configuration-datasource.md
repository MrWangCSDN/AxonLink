# 命名脚本配置的数据源升级

1. 在 Axon 结果库 MySQL 执行 [V97 迁移](../../src/main/resources/db/daoindex/V97__replay_script_config_datasource.sql)。已有 V95 方案继续使用母库，冻结脚本和修订号保留。
2. 在部署密钥管理中生成一次 32 字节随机密钥（例如运行 `openssl rand -base64 32`），按 Base64 保存为 Axon 服务的环境变量 `REPLAY_DB_SCRIPT_PASSWORD_KEY`。同一结果库的各服务实例使用同一密钥，后续部署与重启沿用该值。保留密钥备份；更换密钥后，原来保存的密码无法解密，需要重新填写并保存。母库模式和冻结下载无需密钥。
3. 注入密钥后部署并启动新版后端，同时更新打包的前端。Spring 配置项为 `replay-database-comparison.script-config-password-key`，默认通过上述环境变量读取。
4. 在脚本管理中打开已有的“迁移比对”或新建方案，填写 GaussDB 的主机、端口、数据库、Schema、用户名和密码。刷新已选表后核对字段和主键，再保存并下载。源库离线时仍可下载已保存修订。连接密文只保存在结果库，导出的脚本仍使用无 Schema 限定的表名。

密码输入框不回显已存密码。同一认证目标下留空会保留原密码；改变主机、端口、数据库或用户名时需要重新填写。仅修改 Schema 可以继续使用原密码。保存后“本次保存”选项固定本次修订；其他人员已更新时，旧修订下载会提示冲突，可明确选择当前修订再下载。

自动验证包含前端表单与版本下载测试、JDBC 数据源边界测试及临时 MySQL 的 V95→V97 升级验证；未连接现场 GaussDB。首次部署后应使用实际只读账号，验证本环境的连接及元数据读取。
