# 命名脚本配置的数据源升级

1. 在 Axon 结果库执行 [V97 迁移](../../src/main/resources/db/daoindex/V97__replay_script_config_datasource.sql)，然后部署新版后端。已有 V95 方案继续使用母库，冻结脚本和修订号保留。
2. 在部署密钥管理中生成 32 个随机字节，按 Base64 保存为 Axon 服务的环境变量 `REPLAY_DB_SCRIPT_PASSWORD_KEY`。同一结果库的各服务实例使用同一密钥。保留密钥备份，直接更换密钥后，原来保存的密码无法解密，需要重新填写并保存。母库模式和冻结下载无需密钥。
3. 在脚本管理中打开已有的“迁移比对”或新建方案，填写 GaussDB 的主机、端口、数据库、Schema、用户名和密码。刷新已选表后核对字段和主键，再保存并下载。源库离线时仍可下载已保存修订。连接密文只保存在结果库，导出的脚本仍使用无 Schema 限定的表名。
