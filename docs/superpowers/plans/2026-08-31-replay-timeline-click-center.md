# 计划完成时间轴点击日期平滑居中 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 日期列被单击或键盘激活并完成单日查询后，横向时间轴平滑滚动，使该列居中，且首尾日期也能真正居中。

**Architecture:** 在现有时间轴纯函数模块中增加居中留白计算；Vue 组件通过左右两个显式弹性留白元素扩展可滚动边界，并用 `ResizeObserver` 在容器尺寸变化时更新留白。日期列直查完成后调用原生 `scrollIntoView` 平滑居中；下拉查询、端点拖动和首次打开原有滚动行为保持不变。

**Tech Stack:** Vue 3、Vitest、ResizeObserver、Element.scrollIntoView、CSS Flexbox

**Spec:** `/Users/java/obsidian/01 Engineering/axon-link-server/并行回放问题清单-系统设计.md`

## Global Constraints

- 自动居中只由日期列单击、Enter 或空格触发。
- 使用平滑滚动，目标列位于可视区域水平中心。
- 第一个和最后一个真实日期必须能够真正居中。
- 下拉框查询和端点拖动不得自动改变时间轴滚动位置。
- 日期较少且时间轴未溢出时不增加无意义的横向滚动。
- 保留现有单日查询、重合端点双向拖动、Mock 日期和统计逻辑。
- 当前前后端工作区包含用户既有未提交改动；不得重置、清理或覆盖无关文件。

- [x] **Step 3: 实现最小纯函数**

```js
export function timelineCenterGutter(viewportWidth, timelineWidth, pointCount) {
  if (pointCount <= 0 || viewportWidth <= 0 || timelineWidth <= viewportWidth) return 0
  const columnWidth = timelineWidth / pointCount
  return Math.max(0, (viewportWidth - columnWidth) / 2)
}
```
