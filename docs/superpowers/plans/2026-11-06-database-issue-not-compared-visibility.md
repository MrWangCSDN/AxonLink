# 数据库问题不参与比对状态展示范围实施计划

## 目标与设计来源

页面与导出报表排除当前问题状态为“不参与比对”的记录，问题实体及跟踪历史继续保留。

唯一设计来源位于 /Users/java/obsidian/01 Engineering/axon-link-server/回放数据库问题清单-系统设计.md 及数据模型、API接口两页。

## 约束与验证重点

- 只判断 issue_status，问题类型 issue_type 为“不参与比对”的其他状态记录继续展示并统计。
- 列表在统计总数和分页前过滤，筛选候选、候选数量、领域和人员及批次选项使用相同范围。
- 明细 Excel 复用列表查询，领域汇总报表在处理当前状态后再解析导入快照及聚合数量。
- 当前记录、ID 查询、导入状态转换与跟踪历史继续读取完整数据，重新参与比对后保留同一 ID 和历史链。
- 全部被状态过滤的已知批次输出零指标，原本缺少留存明细的批次仍保留未知指标语义。
- 历史批次继续可选，当前状态同样适用于历史报表。版本绑定与字段数计数沿用既有设计。
