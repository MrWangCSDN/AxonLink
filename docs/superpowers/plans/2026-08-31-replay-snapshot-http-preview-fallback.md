# 内网 HTTP 快照预览降级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 快照图片自动复制失败时，保留已完成的下载并打开同一 PNG 的预览，让内网 HTTP 用户通过浏览器右键复制图片。

**Architecture:** `downloadAndCopyCompletionSnapshot` 继续负责一次下载和一次剪贴板尝试；复制成功时立即释放对象 URL，复制失败时把该 URL 作为 `previewUrl` 转交给弹窗。`ReplayPlannedCompletionModal` 独立管理预览生命周期，预览仅由右上角关闭按钮关闭，并在关闭、重新拍摄或父模态框关闭时释放 URL。

**Tech Stack:** Vue 3 Composition API、Canvas/Blob/Object URL、Vitest

**Spec:** `/Users/java/obsidian/01 Engineering/axon-link-server/并行回放问题清单-系统设计.md`

## Global Constraints

- 自动复制成功时不展示预览，原成功提示和相机动画保持不变。
- 自动复制失败时不重复下载、不重新生成图片，复用第一次下载使用的同一对象 URL。
- 预览提示固定为“快照已保存，请右键复制图片”。
- 点击预览遮罩不得关闭，只能点击右上角 `×` 关闭。
- 预览关闭、重新拍摄、父模态框关闭和组件卸载时必须释放对象 URL。
- 不新增第三方依赖、后端接口、数据库字段或服务端文件。
- 保留工作区已有未提交改动，不重置、不清理、不覆盖无关文件。
